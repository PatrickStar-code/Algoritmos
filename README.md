# 📚 Repositório de Algoritmos --- Prof. Lovsi

Este repositório reúne **todos os projetos, exercícios e atividades
práticas** desenvolvidos ao longo da disciplina de **Algoritmos**
ministrada pelo Prof. Lovsi.

O objetivo é centralizar o conteúdo produzido em aula, organizar os
códigos e facilitar a revisão para provas, estudos e futuras consultas.

------------------------------------------------------------------------

## 🎯 Objetivo da Disciplina

-   Desenvolver o raciocínio lógico
-   Compreender estruturas de controle
-   Trabalhar com variáveis, operadores e tipos de dados
-   Implementar algoritmos utilizando pseudocódigo e/ou linguagem de
    programação
-   Resolver problemas computacionais de forma estruturada

------------------------------------------------------------------------
